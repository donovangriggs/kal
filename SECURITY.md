# Security

kal runs Claude Code workers unattended with a full shell as your user. They are not sandboxed: see
[Safety](README.md#safety) for what is and isn't enforced.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/donovangriggs/kal/security/advisories/new), not in a public
issue. kal is a personal project with best-effort support, so there is no response-time promise, but reports are
read and taken seriously.

Only the latest version is supported.
