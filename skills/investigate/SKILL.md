---
name: investigate
description: Research a question against primary sources in a background agent and save the cited findings as one Markdown file in the repo. Use when a topic needs researching, when documentation or API facts must be gathered, or when reading work should be handed off while the main session keeps going.
---

Hand the research to a **background agent** so the main session can keep working while it reads.

Brief the agent to:

1. Answer the question from **primary sources**: official documentation, source code, specifications, first-party APIs. A blog post or summary about a source is not the source. Trace each claim back to whoever owns it.
2. Write everything it found into one Markdown file, with a source cited for every claim.
3. Put that file wherever the repo already keeps notes like it. If there's no convention, choose a sensible location and say where it went.
